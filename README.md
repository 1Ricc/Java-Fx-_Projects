# Java FX Exam Projects

JavaFX + Maven solutions for the *Programmazione 2* exams at UniTn.

| Folder | Description |
|--------|-------------|
| `farmacia/` | A pharmacy simulator where customers buy medicines using prescriptions. Handles expiry dates, stock checks, and various purchase exceptions. |
| `pok/` | A Pokémon-inspired card game where players manage energy cards (fire, water, dark, neutral) and use them to summon creatures and trigger attacks. |
| `quests/` | An RPG quest manager for a character named Geraldo. Supports multiple quest types (main, secondary, contract, DLC, treasure hunt) with level requirements and sorting. |
| `ruz/` | A Ruzzle-style word game where players find words on a letter grid. Cells can carry letter or word score bonuses, and results are tracked on a leaderboard. |
| `Streaming/` | A streaming catalogue browser that lists movies, series, and anime. Titles can be filtered by series and sorted by name, year, or type. |
| `soluzione_giu_2025_brostelle/` | A combat simulator where "Bros" soldiers attack targets using different attack patterns (single, blast, lobber). Bros can level up and targets have HP that depletes on hit. |
| `of/` | A shop manager for electric fans (ceiling, wall, floor-standing). Fans are catalogued by brand, power source (plug, battery, mechanical), and cost. |

## Requirements

- Java 17+
- JavaFX 17
- Maven

## Run

```bash
cd <project-folder>
mvn javafx:run
```
